# Quantum Metric for Gemini Enterprise

Analyze funnels, errors, friction and session replays in Quantum Metric to find and fix digital experience issues.

## Install

In Gemini, add the Quantum Metric plugin, then sign in with your Quantum Metric account when prompted.

## Configure

The server uses Quantum Metric sign-in (OAuth). Every call runs as you, with your role, permissions, workspace and timezone. No token is created or stored.

| Setting | Value |
|---|---|
| Endpoint | `https://api.quantummetric.com/mcp` |
| Subscription | Chosen when you sign in |

## Skills

- `quantum-metric-getting-started`: confirms the subscription, workspace and timezone, and fixes connection and access problems
- `quantum-metric-data-analysis`: answers funnel, conversion, error and trend questions with verified numbers
- `quantum-metric-session-review`: explains what a visitor experienced in one or more sessions, with a replay link
- `quantum-metric-saved-queries`: creates a saved query after validating it and confirming the details
- `quantum-metric-monitoring-workflows`: reviews and runs monitoring agents and workflows, and reads their results
